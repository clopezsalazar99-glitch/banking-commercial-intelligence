# Inteligencia Comercial Bancaria

## Descripción del proyecto

Proyecto de análisis de información bancaria enfocado en evaluar
el desempeño comercial, identificar patrones de comportamiento
de clientes y generar indicadores para apoyar la toma de decisiones.

Se utilizarán herramientas de análisis de datos y visualización
para transformar información en hallazgos relevantes para el negocio.

## Objetivos

- Analizar información de clientes y campañas comerciales.
- Evaluar el desempeño de las estrategias comerciales.
- Construir indicadores clave de desempeño (KPIs).
- Identificar segmentos de clientes con mayor conversión.
- Generar recomendaciones basadas en datos.

## Herramientas

- Python: limpieza, transformación y análisis de datos.
- SQL: consultas, validación y construcción de indicadores.
- Power BI: visualización y seguimiento de KPIs.

## Fuente de datos

Bank Marketing Dataset
UCI Machine Learning Repository.
